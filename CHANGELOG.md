## 0.1.0 - 2026-09-03

### Added

- canonical `orbitfabric-openc3-cosmos-adapter` product identity;
- Scenario-driven `verification_projection` as the initial declared operation;
- OpenC3 COSMOS v7.3.0 as the first validated downstream baseline;
- target-owned Projection Profile and Verification Projection Plan schemas;
- complete 21-area Integration Coverage declaration and user-facing matrix;
- canonical native COSMOS runtime acceptance with persistent Script Runner evidence;
- Adapter Manager installed lifecycle and provider-neutral release proof;
- consumer-facing Scenario Verification Projection example exercised from an installed wheel;
- role-separated User, Developer / Contributor and Maintainer / Publisher documentation.

### Scope

The first release intentionally does not add a generic mission-data `project` operation merely for symmetry with another adapter. The declared initial scope contains no known `NOT_IMPLEMENTED` gap.

### Migration note

The historical `OrbitFabric-OpenC3-COSMOS-PoC` remains evidence and regression reference. Experiment, G6 and G9 scaffolding is not part of the canonical product structure.

Historical note: source version `0.1.0` alone was only release-preparation metadata; the `v0.1.0` tag and GitHub Release were subsequently published on 2026-09-03 as separate lifecycle events.
